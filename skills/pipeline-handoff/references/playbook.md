# Pipeline Handoff playbook


Map destination fields before producing an import: accounts/domains, contacts/emails, owner, stage, source/date, qualification rationale, contact status, next action and evidence notes. Preview rows and preserve distinct contacts. A CRM upload needs destination account/object/update policy and authorization. Local CSV preparation does not.

Experiment sheet: segment hypothesis, source plan, total authorized collection budget, sample, qualified definition, observation window and success threshold. Measure discovery-to-qualified yield and contactable yield before optimizing for raw volume. Attribute overlap and retain zero-result/partial searches.

Pipeline entries need real sales context. A collected email is not an opportunity. Meetings/replies/revenue require actual evidence. Scheduling recurring prospecting belongs to a verified host scheduler with bounded budget and notification intent; VibeLeads does not run on its own.


For exact owned routes, schemas and limitations, read the relevant Handoff rows in the [source catalog](../../lead-engine/references/source-catalog.md). Read only relevant schemas, and refresh them before live collection.
