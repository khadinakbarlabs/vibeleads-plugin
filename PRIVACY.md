# VibeLeads package privacy information

This skills-only package contains instructions, public source schema snapshots, examples, and offline quality/report/maintainer tools. It contains no hosted VibeLeads service, data-provider key or automatic telemetry. The offline helpers read specified local files and write requested outputs; they do not transmit them. Visual reports use embedded local styles/scripts, with no remote assets or tracking. Clicking an evidence link can open the user's source site.

When the host follows the skills to collect data, the host assistant and the user’s chosen data service process submitted queries and results under their own policies. Live collection uses the user’s account. Runs, datasets and retained outputs may contain business/contact data. Keep queries minimal, use public business data, and review exports for unnecessary private information.

Users control local output storage and provider-account data retention/deletion. The package does not automatically delete third-party records. Do not place API keys, private logs or contact datasets in the repository or release archives. This document describes the local implementation; published service policies and commitments need separate owner review.

Business briefs, session handoffs, deliberate feedback and private reports can be saved in the user's chosen workspace outside the plugin. Host memory is optional and has its own scope/deletion controls. No cross-host persistence or model training is implied. Product feedback is not sent to the developer automatically. Real recurring jobs, when requested, use the host's scheduler and its data/usage policies; the plugin does not activate a job on installation.
