# VibeLeads package privacy information

This skills-only package contains instructions, public source schema snapshots, examples, and offline quality/maintainer tools. It contains no hosted VibeLeads service, data-provider key or automatic telemetry. The offline quality helper reads specified local files and writes requested outputs; it does not transmit them.

When the host follows the skills to collect data, the host assistant and the user’s chosen data service process submitted queries and results under their own policies. Live collection uses the user’s account. Runs, datasets and retained outputs may contain business/contact data. Keep queries minimal, use public business data, and review exports for unnecessary private information.

Users control local output storage and provider-account data retention/deletion. The package does not automatically delete third-party records. Do not place API keys, private logs or contact datasets in the repository or release archives. This document describes the local implementation; published service policies and commitments need separate owner review.
