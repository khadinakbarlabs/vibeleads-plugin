# Inspiration and source notices

VibeLeads workflows are original instructions informed by these public reference implementations and official guides:

- [Anthropic sales plugins](https://github.com/anthropics/knowledge-work-plugins/tree/main/sales): evidence-led company research, task-focused sales workflows, and useful fallbacks when connectors are absent.
- [Corey Haines’ Marketing Skills prospecting workflow](https://github.com/coreyhaines31/marketingskills/tree/main/skills/prospecting): distinct local, B2B and SaaS prospecting motions and source-aware qualification. Consult that repository’s license before reusing its content; this package does not reproduce its skill text.
- [Postiz agent](https://github.com/gitroomhq/postiz-agent): a skills package invoking a separately installed authenticated CLI.
- [Existing VibeLeads project](https://github.com/khadinakbarlabs/vibeleads): internal source-semantic and provenance concepts informed this separate skills product; no application backend or credentials were copied.
- Official Claude, OpenAI, Cursor and Agent Skills packaging documentation, linked in platform support.

Public Actor input-schema snapshots belong to Khadin Akbar’s published Actors. Snapshots preserve declarative input information and remove defaults/prefills; no private source, build payloads or runtime datasets are included. Sources were inspected October 5, 2026. Names of third-party services identify source coverage or comparisons, not affiliation, certification or licensed integration.

The listing icon uses the owner-selected Momentum direction: a flowing V ending in an ascending arrow on the established violet background. The final artwork was generated for this project; no third-party logo artwork is included.
