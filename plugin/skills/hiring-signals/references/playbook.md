# Hiring Signals playbook


Company career sites and ATSs (Greenhouse, Lever, Ashby, Workable, Workday) can provide employer-owned evidence. Job boards (LinkedIn, Indeed, Google Jobs, Wellfound, Glassdoor and regional boards) add discovery breadth and duplication. Aggregators are coverage aids, not independent corroboration when they copy one vacancy.

Use separate query sets for genuinely different roles: growth marketer, SEO specialist, demand generation. Preserve requested work mode and geography. Regional routes include Bayt/GulfTalent, Naukri, Seek and Stepstone where relevant. Employer identity may be obscured by staffing agencies; unresolved employer is a review row.

Filter using actual posting date and timezone. If date is unavailable, do not count the record as within a strict window. First hire/expansion claims need additional company/team evidence. Many open roles can reflect replacement hiring; timing remains an observed recruiting initiative.


For exact owned routes, schemas and limitations, read the relevant Hiring and expansion rows in the [source catalog](../../lead-engine/references/source-catalog.md). Read only relevant schemas, and refresh them before live collection.
